# Python for Dummies 🐍

A beginner-friendly guide to learning Python syntax, fundamental programming concepts, and practical coding patterns through simple, self-contained examples.

---

## 📌 Prerequisites & Getting Started

1. **Install Python:** Ensure you have Python 3.10+ installed. Download it from [python.org](https://www.python.org/) if needed.
2. **Clone the Repository:**
   ```bash
   git clone [https://github.com/ravindrasinghshah/python-for-dummies.git](https://github.com/ravindrasinghshah/python-for-dummies.git)
   cd python-for-dummies
   ```
3. **Run Any Script:**
   ```
   python 01_basics\identation.py
   ```

## 🎯 How to Use This Repo

- Read along: Open any script in your code editor to see the explanation and comments.

- Run the code: Execute each script in your terminal to see the live output.

- Tinker & Break: Modify values, add edge cases, and run the script again to see what changes.

- Practice: Try completing the challenges in loop_exercises.py before checking the solution patterns.
